# Конвертер учебного конфигурационного языка в XML (Вариант №26)

Инструмент командной строки на языке Python для трансляции конфигурационных файлов из учебного конфигурационного языка в формат XML. Поддерживает объявление констант на этапе трансляции, вычисление постфиксных выражений и выявление синтаксических ошибок с указанием строки и позиции.

---

```text
cli-configuration-language-encoder/

```

## Использование

Инструмент принимает путь к входному файлу через аргумент командной строки и выводит результат в формате XML в стандартный поток вывода (`stdout`). Сообщения об ошибках направляются в `stderr`.

### Запуск

```bash
python src/cli.py path/to/config.*
```

## Синтаксис учебного конфигурационного языка

### 1. Типы значений
* **Двоичные числа**: задаются в формате `0[bB][01]+` (например, `0b1010`, `0B111`). При трансляции преобразуются в десятичное представление.
* **Строки**: заключаются в одинарные кавычки `'Это строка'`.
* **Словари**: поддерживают произвольную вложенность:
  ```text
  dict(
      имя = значение,
      имя = значение
  )
  ```
* **Имена (идентификаторы)**: латинские буквы `[a-zA-Z]+`.

### 2. Константы и вычисления на этапе трансляции
* **Объявление константы**:
  ```text
  имя <- значение;
  ```
* **Константные выражения** записываются в постфиксной форме внутри конструкции `?[...]`:
  ```text
  ?[имя 1 +]
  ```
* **Поддерживаемые операции и функции**:
  * `+` — сложение двух чисел или конкатенация двух строк.
  * `chr` — преобразование числового кода символа Unicode в строку из одного символа (`?[0b1000001 chr]` → `'A'`).
  * `mod` — вычисление остатка от деления двух чисел (`?[0b1010 0b11 mod]` → `1`).

## Примеры работы

### Входной файл (`tests/dif_tests/1.txt`)
```text
basePort <- 0b11111010000;
portOffset <- 0b1010000;
envPrefix <- 'prod_';

dict(
    serviceName = ?[envPrefix 'api_gateway' +],
    listenPort = ?[basePort portOffset +],
    workerThreads = 0b1000,
    database = dict(
        host = 'db.internal',
        port = 0b1010100111000,
        shardIndex = ?[0b10111 0b100 mod]
    )
)
```

### Выходной XML (`stdout`)
```xml
<config>
  <constant name="basePort">
    <value type="number">2000</value>
  </constant>
  <constant name="portOffset">
    <value type="number">80</value>
  </constant>
  <constant name="envPrefix">
    <value type="string">prod_</value>
  </constant>
  <item type="dict">
    <serviceName type="string">prod_api_gateway</serviceName>
    <listenPort type="number">2080</listenPort>
    <workerThreads type="number">8</workerThreads>
    <database type="dict">
      <host type="string">db.internal</host>
      <port type="number">5432</port>
      <shardIndex type="number">3</shardIndex>
    </database>
  </item>
</config>
```
